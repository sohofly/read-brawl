## 上傳到 GitHub Pages

1. 在 GitHub 建立 repository（建議 **Private**；若要用免費 Pages 則需 Public，內容仍有密碼加密）。
2. 把這個資料夾裡的 `index.html`、`k.txt`、`README.md` 上傳到 repository 根目錄。
3. Settings → Pages → Branch 選 `main` / `root` → Save，幾分鐘後即可用網址開啟。
4. （選用）若要在「熱區佔領」播放音檔：在 repository 建立 `audio/` 資料夾，放入書附 `13.mp3`～`24.mp3`。注意音檔本身不會加密，放在公開 repository 任何人都能下載。

## OpenAI API

- 登入後網頁會用登入密碼自動解開 `k.txt` 中的 API key（與口說亂鬥共用同一個 k.txt），右上角顯示「🤖 AI ✓」。
- 也可在右上角「🤖 AI」輸入自己的 key（只存在該瀏覽器），或用「匯出 k.txt」產生新的加密金鑰檔。
- 預設模型 gpt-4o-mini，可改 gpt-4.1-mini / gpt-4o / gpt-4.1。
